# Ruthvik Reddy — Engineering Portfolio

A portfolio focused on analog and mixed-signal IC design, with digital design, verification, and system projects.

19 project case studies, 27 figures from academic project reports, five illustrated briefs, and an analog resume.

Static HTML, CSS, and JavaScript. No build step. Open index.html locally or serve this directory. Technical figures preserve their source content and aspect ratios; project captions distinguish simulation, layout, and hardware evidence. Team contributions are described in each case study.
